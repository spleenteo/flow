## The slice, decided here

- **Example**, copied word for word by T1 and T3 (lesson 7). Three lines: `territories:`, then `  decisions: {adapter: acme-wiki:territory, where: ENG/decisions, write: comment}`, then `  product: {adapter: acme-wiki:territory, where: PROD/context, write: direct}`. Block style with flow-map values: one line per kind stays readable, and a flat flow line would not.
- **Kinds**, with the repo default when undeclared: `decisions` → `<root>/decisions-log/`; `changelog` → the `changelog` path; `guidelines` → `<root>/development-guidelines.md`; `lenses` → `<root>/impact-lenses.md`; `product` → nothing is read; `archive` → `<root>/work/archive/` with `archived.md`. `work/` and `.version` are never territories.
- **Fields.** `adapter` is the skill's name as the session lists it (`<plugin>:<skill>` for a plugin skill). `where` is the place in the adapter's terms. `write` is a word the adapter's `write` op defines; absent, the adapter's default applies. Territories never go through `presets:` or `stack_presets` (the Gotcha).
- **Changelog.** A `changelog` territory takes the place of the `changelog` path; `labels`, `language` and `decisions` still apply. V3 states the rule and announces it at opening; `flow:docs` keeps writing the path until V5 routes writes through the territory (the mandate's Out).
- **Resolution**, on `/flow:design` § Adapter's pattern. `.flow.yml` is read as § Profile › Reading reads a piece. The run stops, naming the territory, on a malformed entry (unknown kind, or no `adapter` or `where`), on an adapter the session doesn't list (exact name), on an unmet `## Requires`, and on any op that returns `unreachable`. It never falls back to the repo. A stop is one message, and no work is opened or resumed.
- **Invocation.** One per adapter per step: the Skill tool, by name, never by path. The args hold the step's request lines for every territory that adapter serves, several per territory allowed, pairs separated by `; ` and list values by `, `: `op: search; kind: decisions; where: ENG/decisions; write: comment; keywords: cart, total; files: app/models/cart.rb`. Not `flow:docs`'s commas, because keyword lists hold commas. Each request returns, in order, a block headed `<kind>:` (at most ten lines for `search` and `list`), or one line `<kind>: results: <absolute path>`.
- **Ops.** Every op runs `## Requires` first and can return `unmet: <what>`. `op: none` is the Requires-only request → `ready` or `unmet: <what>`; it is the only request V3 sends, at opening. `read` (`name` optional; absent, the document at `where`, for the single-document kinds `guidelines`, `lenses`, `product`, `changelog`) → `read <scratch path>`, the text with its fields as frontmatter, or `missing`. `write` (`name: <id | new>; file: <absolute path>`, fields as frontmatter) → `written` or `proposed <link>`. `search` (`keywords`, optional `files`) → `<identifier> — <excerpt>` lines; `list` (optional `keywords`, `files`) → `<identifier> — <fields>` lines; either may return `none`. The conductor does the `touches` match on the fields `list` returns (as V4 in `slices.md` says); `files` stays an optional filter the adapter may apply. `archive` (`folder: <absolute path>`) → `archived <name>` or `proposed <link>`. Any op → `unreachable: <reason>`. Scratch files come from `mktemp -d`, outside the repo.
- **Fields fallback**: a key/value table at the top of the document (`| Field | Value |`, list values comma-separated, `null` written out) for `kind`, `status`, `description`, `touches`, `work`, `area`, `superseded_by` and `resolved_by`.
- **Opening.** The profile's message lists one line per territory: `<kind> → <where> (<adapter>, write: <write | default>)`. Without `territories:`, nothing is read, resolved or shown.

## Deviations from the mandate

- A malformed entry (unknown kind, or no `adapter` or `where`) also stops the run and names it. The mandate names only a missing skill and an unmet requirement, but a typo must not quietly send a kind back to the repo.
- `op: none` is added beside the five operations: resolution needs a request that runs `## Requires` alone, since V3 sends no other.
- V2's low finding is fixed at the review block (~:305), the phase sources (~:269) and the impact block (~:279) as well as at ~:297: it is the same defect.
- "One adapter invocation per step" is read as one invocation per adapter per step: territories served by different adapters can't share one Skill call.
- Run 3 (unmet `## Requires`) is added to the Done's runs: the mandate's In names that stop, and its Done doesn't test it.
