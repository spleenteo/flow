## The slice, decided here
- **Restore by checkout.** Step 3 keeps the sha of its clear commit as `<clear commit>` (`&& git rev-parse HEAD`). On `unmet`, `unreachable` or `FAILED:`, HEAD is that commit, so `git checkout <clear commit>^ -- <file>` restores the line byte for byte. On the guard's stop it runs only when HEAD and disk both still match `<clear commit>`; otherwise nothing is touched and the report names the line (review fix 1).
- **H1: commit after the adapter.** With `scratch`, `changelog-write` writes the version file and commits nothing. It returns `not committed` in place of the sha. The conductor commits `Bump the version to vX.Y.Z` on `written` or `proposed`. On `unmet`, `unreachable` or `FAILED:` it restores the version file with `git checkout --`, or, when the write created it, removes it with `git clean -f -q --`, so a re-run asks `current` again.
- **H2 standalone.** Once the folder has left the repo, the resume can no longer find the work, so `/flow:archive`'s own report carries the merge. On `archived`, run outside `/flow:dev`'s close, the report offers to run Step 6 move 4 (the merge as `merge:` says, with its own ok; push and tag still ask separately), and gives step 4's commands if declined. The resume route covers only a line still pending.
- **M3 by restriction.** A territory source's `when` holds globs only, and `{step:}` and `{phase:}` values are skipped and named. No read moment exists for them, and a packet carries path-scoped sources verbatim. M8 then reduces to the runner's fields holding repo files only.
- **M5 by labelling.** The line becomes `Pending proposals (as recorded, not re-checked): …`. Re-checking accepted proposals is left out of V7.
- **M1.** A failed `op: write` inside a step records nothing. The conductor reports the line and the composed path, and the step goes on. § Resolution's stops stay for resolution and reads.
- **M4.** A called grill never appends or commits. It returns `proposed <link>` and its caller adds the pending line.
- **M10.** `STOP` with `Question: packet unreadable at <path>` is handled as `NO_NESTING`: the conductor reads the packet file itself, then runs the loop in session.
- **Shell first.** Every dictated command is run in a throwaway repo under `$S` before it is written in (lesson 13). `$S` = `/private/tmp/claude-501/-Users-spleenteo-Sites-me-flow/a55fc672-afea-4698-96d9-3664e936b88f/scratchpad`. Use new names, and never `rm`.
- **Quoted texts are copied word for word** (lesson 7). This plan's quoted text is the single source for every string that recurs across tasks (`not committed`, `Pending proposals (as recorded, not re-checked):`, `— archive:<dir> — `, `packet unreadable at <path>`): T5 and T7 run before T2 and take them from here, not from T2's commit.
